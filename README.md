# Previsao-de-Churn-de-Clientes-e-Estrat-gia-de-Retencao.ipynb
Prever quais clientes têm alta probabilidade de cancelar serviços ou migrar de banco nos próximos 30 a 90 dias, segmentando-os por Valor de Vida do Cliente (CLV).  Unir a predição da probabilidade de cancelamento ao impacto financeiro para direcionar estratégias de retenção eficazes.
